# T-04 — Je marque une tâche terminée

Module : M1 Tâches · Ordre de construction : 1 (Socle) · Agent : **tasks-planning** · Statut : à faire

## Rappel PRD (section 4, M1)

| ID | User story | Critères d'acceptation |
| --- | --- | --- |
| T-04 | Je marque une tâche terminée | Case cochée, texte barré, date de fin horodatée ; annulation possible 5 s |

PRD 5 : éléments terminés barrés et descendus en bas ; raccourci Espace = terminer / rouvrir l'élément sélectionné. ADR 0005 : annulation par `UndoStack`.

## Références visuelles

- Main.html / PC-Aujourdhui.html : case 28 px (iPhone) / 26 px (PC), aria-label « Terminer : <titre> » ; cochée : fond #2E2150, coche blanche, aria-pressed="true", aria-label « Rouvrir : <titre> », titre barré #5E557A, ligne en bas de liste.
- Detail.html : bouton « Marquer comme terminée ».
- Gestes.html : message bas d'écran (fond #2E2150, bouton « Annuler » #F2A7A0, role="status").
- Semaine.html / PC-Semaine.html : cases plus petites, tâches terminées barrées.

## Critères testables

1. **Étant donné** une tâche non terminée, **quand** je coche sa case (Aujourd'hui, Semaine) ou touche « Marquer comme terminée » (détail), **alors** la case est cochée, le titre barré, `status = done` et `doneAt` = instant courant (horodatage ISO de l'appareil).
2. **Étant donné** une tâche venant d'être terminée dans Aujourd'hui, **alors** elle descend sous les éléments non terminés.
3. **Étant donné** une tâche terminée, **alors** un message « « <titre> » terminée » avec bouton « Annuler » s'affiche 5 s ; **quand** je touche « Annuler » dans ce délai, **alors** la tâche redevient non terminée, `doneAt` = null, et elle reprend sa place.
4. **Étant donné** le message disparu, **quand** j'appuie sur Ctrl+Z (PC, hors champ de saisie), **alors** la complétion est annulée (T-13).
5. **Étant donné** une tâche terminée, **quand** je décoche sa case (« Rouvrir »), **alors** elle redevient non terminée, `doneAt` = null, et elle remonte à sa place.
6. **Étant donné** une ligne sélectionnée au clavier (PC), **quand** j'appuie sur Espace, **alors** la tâche est terminée (ou rouverte si déjà terminée).
7. **Étant donné** une occurrence de tâche récurrente, **quand** je la termine, **alors** l'occurrence suivante est créée (T-09) ; **quand** j'annule, **alors** l'occurrence suivante créée est supprimée.
8. **Étant donné** une tâche terminée aujourd'hui, **quand** je change de jour (minuit), **alors** elle n'est plus dans Aujourd'hui mais reste à sa date en Semaine et dans les tâches terminées (T-07).
9. Le titre barré conserve un contraste AA ; l'état est annoncé aux lecteurs d'écran par aria-pressed et le libellé « Rouvrir ».

## Hors de cette story

- Valider une routine depuis la liste : R-03 (même case, agent routines).
- Balayage vers la droite pour terminer : A-07 (ordre 5).
- Terminer depuis la notification : N-03 (ordre 5).
- Liste des tâches terminées : T-07. Proposition de terminer après Focus : F-04.

## Ordre des sous-tâches

1. domain : `completeTask` / `reopenTask` (invariant status ⇔ doneAt), déclenchement de l'occurrence suivante (avec T-09) ; tests.
2. Repository `TaskRepository.setStatus`.
3. Cas d'usage + commande annulable `UndoKind 'complete'` (ADR 0005) ; i18n du message.
4. UI : case dans lignes Aujourd'hui et cartes Semaine, bouton du détail, raccourci Espace, tri terminées en bas.
5. Tests Testing Library (états, aria), e2e (cocher, annuler sous 5 s, Ctrl+Z).
6. qa-test, code-reviewer, vérification product-owner.

## Écarts

- Main-Edition.html affiche « Fait » sans barré pour une tâche terminée en mode édition : comportement propre à A-05, accepté.
- Semaine : PC-Semaine.html laisse les tâches terminées à leur place (pas descendues). Proposition : en Semaine, pas de déplacement en bas (conforme maquette) ; règle « en bas » limitée à Aujourd'hui et « Un jour ».
