# RC-02 — Je filtre les résultats

Module : M14 Recherche · Ordre de construction : 2 · Agent : **spaces-goals** · Statut : à faire
Dépend de : RC-01.

## Rappel PRD (section 4, M14)

| ID | User story | Critères d'acceptation |
| --- | --- | --- |
| RC-02 | Je filtre les résultats | Espace, projet, type, statut (à faire / fait), période |

## Références visuelles

- Recherche.html : quatre puces « Espace : Tout ∨ », « Type : Tous ∨ », « Statut : Tous ∨ », « Période ∨ » (la puce active passe en #2E2150 / texte blanc). Aucune puce « Projet » n'est dessinée.

## Critères testables

1. **Quand** je touche « Espace : Tout », **alors** Tout / Pro / Perso sont proposés ; le choix filtre les résultats et le compteur (« 5 résultats » devient « 3 résultats »).
2. **Étant donné** un espace Pro choisi, **alors** une puce « Projet : tous ∨ » apparaît (projets actifs de l'espace) ; sous « Tout » ou « Perso » sans projet, elle est absente.
3. **Quand** je choisis « Type : Checklists », **alors** seuls les résultats de ce type restent (types : Tous, Tâches, Routines, Événements, Checklists, Objectifs).
4. **Quand** je choisis « Statut : À faire » ou « Fait », **alors** seuls les tâches et objectifs correspondants restent (objectif : ouvert / atteint) ; les autres types sont masqués tant qu'un statut est choisi.
5. **Quand** je choisis « Période », **alors** Cette semaine, Ce mois, 30 derniers jours, Choisir des dates (deux sélecteurs T-14) sont proposés ; le filtre porte sur la date de l'élément (tâche, événement, date de la checklist, jour d'un « fait ») ; les éléments sans date (« Un jour », checklists sans date, routines) sont exclus quand une période est choisie.
6. **Alors** les filtres se combinent (ET) ; une puce active est mise en évidence et son libellé dit la valeur (« Type : Tâches ») ; « Réinitialiser » les remet à zéro.
7. **Alors** à l'ouverture, l'espace du filtre global (ES-03) est repris ; changer la puce de la recherche ne modifie pas le filtre global ; les filtres de recherche ne sont pas mémorisés.
8. **Alors** chaque changement de filtre relance la requête en < 200 ms avec 5 000 tâches ; filtres appliqués dans la requête, pas après.
9. Menus de puce : listes natives sur iPhone (roue), menu déroulant au clavier sur PC ; noms accessibles « Filtre Type : Tous ».

## Hors de cette story

- Tri personnalisé ; filtres enregistrés.

## Décisions (validation automatique)

- D1 — Puce « Projet » ajoutée (PRD : projet) seulement quand un espace unique est choisi ; la maquette n'en dessine pas (écart noté).
- D2 — Statut : concerne tâches et objectifs ; les autres types sont masqués sous un statut.
- D3 — Période : quatre choix, filtre sur la date de l'élément ; éléments sans date exclus.
