# A-05 — Je passe en mode édition

Module : M2 Aujourd'hui · Ordre de construction : 1 (Socle) · Agent : **tasks-planning** · Statut : à faire

## Rappel PRD (section 4, M2)

| ID | User story | Critères d'acceptation |
| --- | --- | --- |
| A-05 | Je passe en mode édition | Interrupteur « − » en bas à gauche : bouton de suppression et poignée de déplacement sur chaque élément, sélection multiple (déplacer, reporter, supprimer) ; même interrupteur pour revenir au mode normal |

## Références visuelles

- Main.html : interrupteur « Mode édition » (64 × 36, fond #2E2150, curseur blanc à gauche avec « − »), aria-pressed="false".
- Main-Edition.html : interrupteur à droite, curseur #F2A7A0, aria-pressed="true" ; par ligne : rond de sélection à gauche (« Sélectionner : <titre> » / « Désélectionner : <titre> », sélectionné : fond #3A2A66 + coche), bouton rond « − » rouge (« Supprimer : <titre> », fond #FBE7E4, trait #A1271C), poignée « Déplacer » ; ligne sélectionnée fond #F1EEF7 ; barre « 2 sélectionnées » (fond #2E2150) avec « Déplacer », « Reporter », « Supprimer » (#F2A7A0) ; une tâche terminée affiche « Fait ».
- PC-Aujourdhui.html : même interrupteur en bas à gauche.

## Critères testables

1. **Étant donné** Aujourd'hui en mode normal, **quand** j'active l'interrupteur « Mode édition », **alors** chaque tâche affiche rond de sélection, bouton « − » et poignée ; les cases « Terminer » sont remplacées par les ronds de sélection.
2. **Quand** je touche « − » sur une ligne, **alors** la suppression suit T-08 (confirmation, corbeille, annulation 5 s).
3. **Quand** je fais glisser une poignée, **alors** l'élément est réordonné (A-02).
4. **Quand** je sélectionne 2 éléments, **alors** la barre « 2 sélectionnées » apparaît au-dessus du champ d'ajout ; « 1 sélectionnée » au singulier ; sans sélection la barre est masquée.
5. **Quand** je touche « Reporter » dans la barre, **alors** le menu de T-05 s'ouvre et s'applique à toute la sélection ; une seule annulation rétablit tout (T-13).
6. **Quand** je touche « Supprimer » dans la barre, **alors** une confirmation « Supprimer 2 tâches ? » s'affiche, puis suppression vers la corbeille, annulable en une fois.
7. **Étant donné** 2 tâches sélectionnées, **quand** je touche « Déplacer », **alors** je choisis un espace (Pro / Perso) puis un projet de cet espace (ou « aucun projet ») ; les 2 tâches y passent en une seule action, annulable en une fois (Q12, ES-05). « Déplacer » ne change jamais la date (c'est le rôle de « Reporter »).
8. **Étant donné** le mode édition actif et une routine dans la liste, **alors** la routine n'affiche ni rond de sélection, ni bouton « − », ni poignée ; elle ne peut pas être sélectionnée, supprimée ni déplacée depuis Aujourd'hui (Q13) ; sa gestion se fait dans l'onglet Routines.
9. **Quand** je désactive l'interrupteur, **alors** la sélection est vidée et le mode normal revient ; le mode édition n'est pas mémorisé au redémarrage ni au changement d'onglet.
10. **Étant donné** le PC, **alors** Échap quitte le mode édition ; Ctrl+clic / Maj+clic étendent la sélection ; Suppr supprime la sélection (avec confirmation).
11. Le champ « Ajouter une tâche » reste utilisable ; objectif et événements ne sont pas sélectionnables.
12. Tous les boutons ont un libellé accessible incluant le titre (« Supprimer : Envoyer la facture ») ; zones tactiles ≥ 44 pt (la pastille « − » de 36 px reçoit une zone de toucher étendue).

## Hors de cette story

- Mode édition de « Un jour » : SD-04 (même composant). Déplacement d'espace unitaire : ES-05.

## Ordre des sous-tâches

1. Store : `editMode`, `selection` ; cas d'usage par lot (reporter, supprimer, déplacer) en une transaction et une commande annulable.
2. UI ligne en mode édition, barre de sélection, interrupteur (composant partagé avec SD-04).
3. Raccourcis PC (Échap, Ctrl/Maj+clic, Suppr).
4. Tests Testing Library et e2e (sélection de 2 tâches, reporter, annuler).
5. qa-test, code-reviewer, vérification product-owner.

## Décisions d'Ali (2026-10-02)

- **Q12** : « Déplacer » dans la barre de sélection multiple change l'espace et/ou le projet des éléments sélectionnés (ES-05 « par lot ») ; il ne change pas la date. Critère 7 ajusté.
- **Q13** : en mode édition d'Aujourd'hui, les routines ne sont ni sélectionnables ni supprimables ni déplaçables (sans rond, sans « − », sans poignée). Écart avec Main-Edition.html accepté. Critère 8 ajusté.
