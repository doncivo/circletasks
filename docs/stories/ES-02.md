## Critères testables

1. **Étant donné** toute création (tâche, routine, objectif ; événement et checklist à l'ordre 2), **alors** l'élément a un `space_id` non nul existant ; la base refuse un `space_id` nul (contrainte NOT NULL + clé étrangère).
2. **Étant donné** le filtre « Perso », **quand** je crée une routine, **alors** « Perso » est présélectionné ; en « Tout », « Pro ».
3. **Étant donné** le sélecteur d'espace d'une fenêtre d'ajout, **quand** je choisis l'autre espace, **alors** l'élément est créé dans cet espace et le filtre actif ne change pas.
4. **Étant donné** un élément créé dans un espace hors filtre (ex. Perso pendant le filtre Pro), **alors** un message bref « Ajouté dans Perso » s'affiche, car l'élément n'est pas visible dans la liste filtrée.
5. **Étant donné** la fiche détail (tâche) ou le formulaire (routine), **alors** l'espace est affiché avec sa couleur.
6. Les données d'exemple (sampleData) et tout import respectent la règle (test sur toutes les tables métier).

## Hors de cette story

- Changer l'espace d'un élément existant : ES-05. Filtre : ES-03. Saisie « #pro » : Q-06.

## Ordre des sous-tâches (spaces-goals)

3. UI : sélecteur d'espace commun ; message « Ajouté dans … ».
4. Tests, qa-test, code-reviewer.
