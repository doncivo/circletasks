## Références visuelles

Aucune maquette de la zone de notification. Icône : celle de l'application ; libellés en français depuis src/i18n.

## Critères testables

1. **Étant donné** la fenêtre ouverte, **quand** je clique la croix de fermeture (ou Alt+F4), **alors** la fenêtre est masquée, le processus continue et l'icône CircleTasks reste dans la zone de notification.
2. **Étant donné** l'app masquée, **quand** je clique (simple clic gauche) l'icône, **alors** la fenêtre réapparaît au premier plan, sur l'écran où elle était.
3. **Quand** je fais un clic droit sur l'icône, **alors** le menu affiche, dans l'ordre : « Ouvrir CircleTasks », « Ajout rapide », « Synchroniser », séparateur, « Quitter ».
4. « Ouvrir CircleTasks » : comme le critère 2.
5. « Ajout rapide » : à l'ordre 1, ouvre la fenêtre sur Aujourd'hui avec le champ « Nouvelle tâche » focalisé (comportement de Ctrl+N, T-01) ; remplacé par la mini-fenêtre à Q-01.
6. « Synchroniser » : présent mais grisé tant que M15 n'existe pas (Y-03, ordre 4).
7. « Quitter » : ferme l'app proprement (base fermée, aucune écriture perdue : une tâche créée juste avant est présente au relancement).
8. **Étant donné** l'app déjà lancée, **quand** je la relance (raccourci, menu Démarrer), **alors** aucune seconde instance ne démarre : la fenêtre existante est affichée.
9. Info-bulle de l'icône : « CircleTasks ». Aucune notification Windows n'est affichée lors de la réduction.

## Hors de cette story

- Mini-fenêtre de capture et raccourci global : Q-01 (ordre 3). Synchro : Y-03 (ordre 4). Démarrage avec Windows : D-02.

## Ordre des sous-tâches (desktop-tauri)

1. Rust : tray (Tauri 2 `tray-icon`), interception de la fermeture (`CloseRequested` → hide), plugin single-instance.
2. src/platform : commandes exposées (show, quit) et événement « ajout rapide » → navigation + focus.
3. i18n des libellés du menu (le menu est construit avec les textes de src/i18n transmis au Rust).
4. Tests : cargo test sur la logique, test manuel scripté (procédure courte dans la PR) ; qa-test, code-reviewer.

## Écarts et points à arbitrer

- Le réglage `desktop.closeToTray` existe dans le code ; le PRD ne demande pas de pouvoir le désactiver : pas d'interrupteur dans Réglages.
