# D-04 — J'utilise les raccourcis clavier

Module : M16 Plateforme · Ordre de construction : 3 (rang 15) · Agent : **desktop-tauri** (avec settings-personalization pour la ligne de Réglages) · Statut : à faire
Dépend de : Q-01 (raccourci global par défaut), P-08, F-01 (`list.focus`). PC uniquement.

## Rappel PRD (section 4, M16 ; section 5)

| ID | User story | Critères d'acceptation |
| --- | --- | --- |
| D-04 | J'utilise les raccourcis clavier | Tous les raccourcis de la section 5 fonctionnels ; raccourci global configurable |

## Références visuelles

- Reglages.html : style des lignes (« .r ») ; aucune maquette de la ligne ni du champ de capture d'une combinaison. Ligne « Capture rapide » (valeur « Ctrl+Alt+Espace ») dans la section TÂCHES de Réglages, PC seulement.

## Critères testables

1. **Étant donné** le registre `SHORTCUTS`, **alors** chacune des 19 lignes de la section 5 est branchée à un gestionnaire réel dans l'écran concerné ; un test parcourt les identifiants et échoue si un raccourci n'a aucun gestionnaire monté dans son contexte (liste, Semaine, application).
2. **Alors** un parcours Playwright presse chaque raccourci non global dans son contexte et vérifie l'effet : Ctrl+N (champ d'Aujourd'hui focalisé), Ctrl+K (recherche), Alt+1 à Alt+6 (onglets), Ctrl+1 / 2 / 3 (filtre), Ctrl+← / → (semaine), Espace (terminer), Entrée (détail), ↑ / ↓, Alt+↑ / ↓ (déplacer), Ctrl+D (reporter à demain), Suppr (corbeille), Ctrl+Z (annuler), Ctrl+Maj+F (Focus, F-01), Ctrl+, (Réglages), Ctrl+/ (aide, P-08), Échap (fermer), Ctrl+Maj+D (dupliquer).
3. **Alors** l'effet est le même au clavier AZERTY et QWERTY (comparaison sur `event.code` pour les chiffres, `event.key` pour les lettres : tests sur les deux dispositions) ; AltGr n'est jamais pris pour Ctrl+Alt dans l'application.
4. **Alors** dans un champ de saisie, seuls les raccourcis déclarés `inEditable` agissent ; Suppr, Espace, Ctrl+D, Ctrl+Maj+D ne perturbent jamais la saisie.
5. **Étant donné** Réglages (PC) › TÂCHES, ligne « Capture rapide » : **quand** je clique et presse une nouvelle combinaison (par exemple Ctrl+Maj+Espace), **alors** elle est enregistrée auprès du système, remplace l'ancienne immédiatement (sans redémarrage), s'affiche dans la ligne, dans l'aide (P-08) et dans le menu de la zone de notification.
6. **Alors** une combinaison est refusée avec un message si elle n'a aucun modificateur (Ctrl, Alt ou Maj+un autre), si elle utilise la touche Windows, si elle est réservée (Ctrl+Alt+Suppr, Alt+F4, Alt+Tab, Ctrl+Échap…) ou si elle entre en conflit avec un raccourci de l'application (Ctrl+N, Ctrl+K…).
7. **Étant donné** une combinaison déjà prise par une autre application, **alors** l'enregistrement échoue, l'ancienne combinaison reste active, le message « Combinaison déjà utilisée par une autre application » s'affiche.
8. **Alors** « Rétablir Ctrl+Alt+Espace » remet la valeur d'origine ; « Désactiver » (interrupteur) retire le raccourci global.
9. **Alors** le réglage est local (`shortcut.quickCapture`), écrit par un cas d'usage, relu au démarrage ; si l'enregistrement échoue au démarrage (combinaison prise entre-temps), l'état « indisponible » de Q-01 critère 7 s'affiche.
10. **Alors** Échap pendant la capture d'une combinaison l'annule sans rien changer ; le champ est atteignable au clavier (Entrée pour armer).
11. **Alors** les tests Rust couvrent la validation d'une combinaison (syntaxe, réservées) ; les tests TypeScript le port `GlobalShortcuts` (+ faux).
12. Accessibilité : le champ annonce « Appuyez sur la nouvelle combinaison » ; le résultat est annoncé.

## Hors de cette story

- Personnalisation des autres raccourcis (non demandée). Raccourcis sur iPhone (clavier externe). Mappage de manettes ou souris.

## Décisions (validation automatique)

- D1 — Seul le raccourci global est configurable (PRD) ; les raccourcis applicatifs restent fixes et visibles dans P-08.
- D2 — Combinaison globale : au moins un modificateur parmi Ctrl, Alt (Maj seule insuffisante) ; la touche Windows est refusée (réservée au système).
- D3 — Risque AZERTY : Ctrl+Alt équivaut à AltGr sous Windows ; Ctrl+Alt+Espace est conservé (PRD, Q-01) mais à vérifier par Ali sur son clavier ; si AltGr+Espace gêne la saisie, la combinaison est modifiable ici.
- D4 — Ligne placée en TÂCHES (près des réglages de saisie), pas dans une nouvelle section.

## Ordre des sous-tâches

1. desktop-tauri : port `GlobalShortcuts` (`register`, `unregister`, `isRegistered`), validation Rust, remplacement atomique ; `cargo test`.
2. settings-personalization : cas d'usage, ligne de Réglages et capture de combinaison ; i18n.
3. Branchement des gestionnaires manquants (registre complet) ; parcours Playwright du critère 2 (AZERTY et QWERTY).
4. qa-test, code-reviewer. Vérification réelle du raccourci système par Ali.
