## Ce qui est développable et testable sans compte

Tout le code, via un **simulateur CalDAV local** (`tests/sim/caldav-sim.mjs`, serveur HTTP) servant les réponses d'iCloud : découverte (`/.well-known/caldav`, `current-user-principal`, `calendar-home-set`), liste des calendriers (nom, couleur, `VEVENT` pris en charge), `REPORT calendar-query` avec plage et `expand`, ctag / etag, erreurs 401, 403, 404, 5xx. Les analyses ICS sont testées sur des exemples (fuseaux TZID, flottants, dates seules, annulés, EXDATE, séries développées). Le code est le même sur PC et iPhone (Rust).

## Critères testables

1. **Étant donné** l'écran Agendas, **quand** je choisis iCloud, **alors** un formulaire demande l'identifiant Apple et le mot de passe d'application, avec la consigne « Utilisez un mot de passe d'application, pas votre mot de passe Apple » et le chemin pour le créer.
2. **Quand** je valide, **alors** la découverte CalDAV s'exécute ; succès : un `calendar_account` (provider icloud, label = identifiant) est créé, le mot de passe va dans le coffre système (`token_ref` seul en base), le champ est vidé.
3. **Quand** l'authentification échoue (401), **alors** « Identifiant ou mot de passe d'application incorrect » s'affiche et rien n'est enregistré ; serveur injoignable : « Impossible de joindre iCloud », sans compte créé.
4. **Alors** seuls les calendriers d'événements (`VEVENT`) sont listés (les listes Rappels sont ignorées ici, K-05) avec « Afficher » et Pro / Perso (ES-06, prérempli Pro).
5. **Alors** les événements sont convertis en UTC : heure avec TZID, heure flottante (fuseau courant), journée entière (fin exclue), annulés exclus, séries développées par le serveur (`expand`) ; un événement sans titre s'appelle « (Sans titre) ».
6. **Étant donné** un mot de passe révoqué (401 au rafraîchissement), **alors** le compte devient « Déconnecté », « Reconnecter » (A-09) rouvre le formulaire pré-rempli de l'identifiant.
7. **Alors** le mot de passe n'apparaît ni dans la base, ni dans les journaux, ni dans les rapports d'erreur, ni dans le DOM après validation ; les requêtes utilisent HTTPS (hors simulateur).
8. **Alors** les événements iCloud sont en lecture seule avec la source « iCloud » ; supprimer le compte efface le mot de passe du coffre et les `external_event` (comme K-01 critère 8).
9. Même comportement sur PC et iPhone (même code Rust ; coffre : Credential Manager / Keychain).
