# Q-01 — J'ajoute une tâche depuis n'importe où sur PC

Module : M9 Capture rapide · Ordre de construction : 3 (rang 13) · Agent : **quick-capture** (avec **desktop-tauri** pour la fenêtre et le raccourci) · Statut : à faire
Dépend de : Q-02, Q-06, D-01 (zone de notification), D-02 (démarrage avec Windows). PC uniquement.

## Rappel PRD (section 4, M9 ; section 5)

| ID | User story | Critères d'acceptation |
| --- | --- | --- |
| Q-01 | J'ajoute une tâche depuis n'importe où sur PC | Raccourci global (ex. Ctrl+Alt+Espace) ouvrant une mini-fenêtre |

Section 5 : « Fenêtre flottante par raccourci global », « Global, même app réduite ». D-01 : « Ajout rapide » du menu de la zone de notification ouvre aujourd'hui Aujourd'hui avec le champ focalisé ; remplacé ici par la mini-fenêtre.

## Références visuelles

- Aucune maquette de la mini-fenêtre. Reprendre le champ de PC-Aujourdhui.html (fond #F3F1F6, rayon 12, 48 px, DM Sans 15) dans une carte blanche, bordure #E6E2EE, ombre douce, titre discret « CAPTURE RAPIDE » (13 px, 700, #5E557A), pastille d'aperçu de Q-06 / Q-02 sous le champ, aide « Entrée pour ajouter · Échap pour fermer ».

## Critères testables

1. **Étant donné** l'app réduite, fermée dans la zone de notification ou au premier plan, **quand** je presse Ctrl+Alt+Espace, **alors** une mini-fenêtre sans bordure système (520 × 160 px, centrée sur l'écran actif, toujours au premier plan) s'ouvre en moins de 300 ms avec le champ focalisé.
2. **Quand** je tape « Appeler le notaire demain 10h #pro » puis Entrée, **alors** la tâche est créée comme dans Aujourd'hui (Q-02, Q-06, espace par défaut ES-02), la fenêtre se ferme et le focus revient à l'application précédente.
3. **Quand** je presse Ctrl+Entrée, **alors** la tâche est créée, le champ se vide et la fenêtre reste ouverte avec « Ajoutée : <titre> » pendant 3 s (enchaîner plusieurs tâches).
4. **Quand** je presse Échap, **alors** la fenêtre se ferme sans rien créer ; quand elle perd le focus, elle se ferme seulement si le champ est vide.
5. **Alors** la tâche créée s'affiche dans Aujourd'hui / Semaine sans relancer l'app, avec le message « Ajouté dans Perso » (ES-02) et « Annuler » 5 s dans la fenêtre principale si elle est visible ; Ctrl+Z l'annule (T-13).
6. **Quand** je presse le raccourci pendant que la mini-fenêtre est ouverte, **alors** elle se ferme (bascule) ; un titre vide refusé (T-01) fait trembler le champ sans fermer.
7. **Étant donné** le raccourci déjà pris par une autre application, **alors** l'app démarre normalement, l'échec est consigné dans les logs (D-01) et Réglages › Raccourci global affiche « Combinaison indisponible » avec l'invite à en choisir une autre (D-04).
8. **Étant donné** que Windows redémarre (D-02), **alors** le raccourci est actif dès la session ouverte, l'app démarrant réduite.
9. **Étant donné** la mini-fenêtre, **alors** aucune donnée n'est écrite avant Entrée (aucun brouillon conservé) ; la fenêtre n'ouvre pas la base : elle envoie le texte à la fenêtre principale, seule à écrire.
10. **Alors** le menu de la zone de notification « Ajout rapide » ouvre la mini-fenêtre ; Ctrl+N dans l'app reste le champ d'Aujourd'hui (T-01).
11. Accessibilité : champ nommé « Nouvelle tâche », fenêtre annoncée « Capture rapide », piège de focus, thème clair / sombre suivi (P-02).
12. **iPhone** : rien (bouton + existant ; Q-05 à l'ordre 5).

## Hors de cette story

- Saisie vocale et scan depuis la mini-fenêtre. Choix de la combinaison (D-04). Q-05. Capture du presse-papiers ou de la sélection.

## Décisions (validation automatique)

- D1 — La mini-fenêtre est une seconde fenêtre Tauri (`quick-capture`, toujours au premier plan, masquée au lieu d'être détruite pour ouvrir en < 300 ms) ; elle n'accède pas à SQLite : l'événement `capture:submit { text }` est traité par la fenêtre principale (connexion unique, annulation partagée), qui répond `capture:done`.
- D2 — Enregistrement du raccourci via le plugin global-shortcut dans `src/platform/desktop` (port testable avec un faux) ; la combinaison vient du réglage local `shortcut.quickCapture` (défaut Ctrl+Alt+Espace).
- D3 — Fermeture sur perte de focus seulement si le champ est vide (ne jamais perdre une saisie).
- D4 — Ctrl+Entrée pour enchaîner (non demandé par le PRD, aide visible dans la fenêtre).
- D5 — Si la fenêtre principale a été détruite (cas anormal), la capture la recrée en arrière-plan avant de traiter le texte.

## Ordre des sous-tâches

1. desktop-tauri : fenêtre `quick-capture` (capabilities limitées), enregistrement du raccourci, port `QuickCaptureHost` dans `src/platform/desktop` + faux ; ADR courte si la structure des fenêtres change.
2. quick-capture : écran React de la mini-fenêtre (point d'entrée dédié), cas d'usage « créer depuis le texte », événements fenêtre ↔ principale.
3. Menu de la zone de notification ; i18n ; e2e Playwright (simule `capture:submit`) ; test manuel du raccourci système par Ali (Playwright ne peut pas presser une touche globale).
4. qa-test, code-reviewer.
