# P-06 — Un écran vide m'indique quoi faire

Module : M12 Personnalisation · Ordre de construction : 3 (rang 20) · Agent : **settings-personalization** (avec ui-design-system) · Statut : à faire
Dépend de : tous les écrans à liste de l'ordre 1 et 2, H-01.

## Rappel PRD (section 4, M12)

| ID | User story | Critères d'acceptation |
| --- | --- | --- |
| P-06 | Un écran vide m'indique quoi faire | Chaque écran vide affiche un message et une action (ex. « Aucune tâche aujourd'hui — Ajouter ») |

## Références visuelles

- Main-Vide.html (iPhone) : « Rien de prévu ce dimanche. » (DM Sans, 24 px, 700), trois pastilles rondes de 64 px (#F3F1F6) avec icônes Lucide colorées (livre #3E7C5A, lever de soleil #B9770E, panier #8A6D1F), texte « Ajoutez une tâche ci-dessous, ou planifiez une tâche gardée dans « Un jour ». », bouton contour « Ouvrir « Un jour » · 6 tâches » (44 px, 2 px #2E2150).
- Autres écrans : aucune maquette d'état vide ; même composition réduite (message, texte, une action).

## Critères testables

1. **Étant donné** une base vide, **alors** chaque écran suivant affiche un message et une action visible et utilisable :
   - Aujourd'hui : la composition de Main-Vide.html (action « Ouvrir « Un jour » · N tâches » si N > 0, sinon « Ajouter une tâche », qui focalise le champ) ;
   - Semaine : jour sans tâche déjà couvert par « + Ajouter » (S-04) ; semaine entièrement vide : « Rien de prévu cette semaine. » + « Ajouter une tâche » ;
   - Routines : « Aucune routine pour l'instant. » + « Créer une routine » ; Événements : « Aucun événement en 2026. » + « Ajouter un événement » ; Checklists : « Aucune checklist. » + « Créer une checklist » ;
   - « Un jour » : « Rien en attente. » + « Ajouter à « Un jour » » ; Tâches terminées : « Aucune tâche terminée. » + « Aller à Aujourd'hui » ; Objectif : message d'OB-01 conservé ; Rapport du mois : « Rien à compter en septembre. » + « Aller à Aujourd'hui » ; Recherche : états de RC-01 conservés ; Agendas : état de K-01 conservé.
2. **Alors** chaque état vide est le même composant `EmptyState` de `src/ui` (titre, texte facultatif, icônes facultatives, action principale) ; les écrans existants (ES-03, SD-01, RC, K-01, OB-01) y sont migrés sans changer leurs textes ni leurs captures sauf différence signalée.
3. **Étant donné** un filtre Pro, Perso ou projet (ES-03, ES-04), **alors** le message nomme le filtre (« Aucune tâche Pro aujourd'hui ») et l'action crée dans cet espace ; l'action ne propose jamais un élément qui serait masqué par le filtre.
4. **Quand** je touche l'action, **alors** elle fait ce qu'elle annonce (focus du champ, ouverture de la feuille Ajout sur le bon segment, navigation) ; elle est atteignable au clavier (PC) et fait ≥ 44 pt.
5. **Alors** un test parcourt tous les écrans (PC et iPhone, thèmes clair et sombre, filtres Pro / Perso / Tout) sur base vide et échoue si un écran à liste n'a pas d'`EmptyState` avec une action ; la liste des écrans est tenue dans un registre unique pour qu'un nouvel écran soit couvert.
6. **Alors** l'état vide disparaît dès le premier élément ajouté et réapparaît à la suppression du dernier (annulation comprise), sans scintillement.
7. **Alors** les textes sont dans `src/i18n`, le jour (« ce dimanche ») et le pluriel sont calculés ; contraste AA.
8. Accessibilité : le message est dans un titre de niveau 2 ; les icônes sont décoratives (`aria-hidden`) ; l'apparition de l'état vide est annoncée poliment.

## Hors de cette story

- Illustrations animées, conseils contextuels, tutoriel (P-05).

## Décisions (validation automatique)

- D1 — Les trois pastilles d'icônes ne sont conservées que sur Aujourd'hui (maquette) ; les autres écrans n'ont qu'une icône ou aucune, pour éviter l'encombrement.
- D2 — Registre `emptyStateScreens` testé : aucun écran ne peut échapper à P-06.
- D3 — Tâches terminées, Rapport et « Un jour » reçoivent un état vide non dessiné : mêmes composants et styles que Main-Vide.html.
