# D-02 — L'app PC démarre avec Windows

Module : M16 Intégration système · Ordre de construction : 1 · Agent : **desktop-tauri** · Statut : à faire
Plateforme : PC uniquement. Dépend de : D-01.

## Rappel PRD (section 4, M16)

| ID | User story | Critères d'acceptation |
| --- | --- | --- |
| D-02 | L'app PC démarre avec Windows | Activable en réglage ; démarrage réduit |

## Références visuelles

Pas de maquette Réglages PC ; Reglages.html (iPhone) sert de modèle de ligne avec interrupteur (section « GÉNÉRAL »).

## Critères testables

1. **Étant donné** Réglages sur PC, **alors** la section « GÉNÉRAL » contient l'interrupteur « Démarrer avec Windows », désactivé par défaut ; cette ligne n'existe pas sur iPhone.
2. **Quand** je l'active, **alors** l'entrée de démarrage de l'utilisateur courant est créée (plugin autostart, sans droits administrateur) avec l'argument de démarrage réduit ; le réglage local `desktop.launchAtStartup` vaut vrai.
3. **Quand** je le désactive, **alors** l'entrée est supprimée.
4. **Étant donné** l'option active, **quand** j'ouvre une session Windows, **alors** CircleTasks démarre sans fenêtre visible, avec l'icône dans la zone de notification (D-01).
5. **Étant donné** un lancement manuel (menu Démarrer), **alors** la fenêtre s'affiche normalement.
6. **Étant donné** que l'entrée système a été retirée hors de l'app (Gestionnaire des tâches), **quand** j'ouvre Réglages, **alors** l'interrupteur reflète l'état réel (désactivé).
7. Le démarrage réduit respecte le budget de démarrage (< 2 s jusqu'à l'icône prête).

## Hors de cette story

- Mise à jour : D-03. Raccourci global : Q-01 / D-04.

## Ordre des sous-tâches (desktop-tauri)

1. Rust : `tauri-plugin-autostart` (argument `--minimized`), lecture de l'argument au lancement → fenêtre masquée.
2. src/platform : `getAutostart / setAutostart` ; ligne Réglages (PC seulement).
3. Tests cargo + Vitest (ligne absente sur la mise en page iPhone) ; qa-test, code-reviewer.

## Écarts et points à arbitrer

## Réalisation (2026-10-02, ADR 0006)

Statut : développé, à valider (QA, revue) ; vérification manuelle d'Ali ci-dessous.

- Rust : `tauri-plugin-autostart` avec `--minimized` ; la fenêtre `main` est créée masquée et affichée par le démarrage sauf argument `--minimized` (`desktop.rs`).
- Front : `getAutostart / setAutostart` dans `src/platform/desktop` ; section « GÉNÉRAL » et interrupteur « Démarrer avec Windows » dans `SettingsScreen` (PC seulement, absent si `container.desktop` est nul) ; l'état affiché est celui de l'entrée système, relu à l'ouverture (critère 6), le réglage local est son miroir.
- Tests : Vitest (`SettingsScreen.desktop.test.tsx` : ligne absente hors PC, activation, désactivation, état réel, échec) ; cargo (lecture de l'argument, fenêtre masquée par défaut).

### À vérifier à la main par Ali

1. Critères 2 et 3 : activer l'interrupteur, puis Gestionnaire des tâches > Démarrage (ou `regedit`, `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`) : une entrée CircleTasks avec `--minimized` ; la désactiver la supprime ; aucune invite d'administrateur.
2. Critères 4 et 7 : fermer la session Windows, la rouvrir : pas de fenêtre, l'icône est dans la zone de notification en moins de 2 s.
3. Critère 5 : lancement par le menu Démarrer : la fenêtre s'affiche normalement.
4. Critère 6 : désactiver l'entrée dans le Gestionnaire des tâches, rouvrir Réglages : l'interrupteur est désactivé.
