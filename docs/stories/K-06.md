Aucun nouvel ADR : l'avenant §10 de l'ADR 0008 écrit pour K-05 doit déjà contenir, pour K-06 : (1) la **règle de conflit** par champ (comparaison avec l'empreinte du dernier passage ; un seul côté a changé : il gagne ; les deux : le plus récent gagne, l'autre valeur est écrite dans `conflict_log` et visible dans le journal de Y-04) ; (2) l'**anti-boucle** (une écriture faite par le passage n'est pas relue comme modification de l'autre côté : empreinte et date de modification enregistrées après chaque écriture) ; (3) la **destination d'un rappel créé** (une liste de destination par espace, parmi les listes affichées de cet espace) et le **filet** (échec d'écriture : file locale durable, nouvel essai au passage suivant, visible). ## Décisions recommandées (à valider par Ali)

- D1 — **Création** : réglage « Créer aussi dans Rappels » par espace, **désactivé par défaut**, avec une liste de destination ; ne concerne que les tâches **créées après l'activation** (jamais l'export en masse des tâches existantes). Une tâche créée sur le PC dans cet espace est envoyée vers Rappels au prochain passage de l'iPhone (comme les modifications, K-07).
- D2 — **Suppression** : supprimer une tâche liée dans CircleTasks la supprime aussi dans Rappels, avec une confirmation qui le dit (« Supprimer aussi dans Rappels ? ») ; pas d'option « seulement ici » en v1 (elle exigerait un marqueur « ignoré » pour ne pas réimporter).
- D3 — **Achèvement** : « Terminer » une tâche liée marque le rappel terminé avec sa date d'achèvement ; « Rouvrir » le rend à faire. Rappel récurrent : voir K-05 D4 (message, pas d'écriture).
- D4 — **Date** : une tâche liée qui perd sa date et devient « Un jour » efface l'échéance du rappel ; le report automatique T-06 n'est pas renvoyé (K-05 D5).

## Critères testables sans Mac

Légende comme K-05 ; le faux magasin EventKit enregistre chaque écriture et sa date.

1. **[U]** **Étant donné** une tâche liée à faire, **quand** je la termine dans CircleTasks (case, balayage A-07, fiche), **alors** le rappel du faux magasin est terminé avec la date d'achèvement au passage suivant (passage `push` immédiat sur iPhone après l'annulation de 5 s, ADR 0008 §10.9 écart 5 ; au prochain passage de l'iPhone si la tâche a été terminée sur le PC) ; « Annuler » 5 s (T-13) avant le passage ne produit aucune écriture, après le passage rouvre aussi le rappel.
2. **[U]** **Quand** je termine un rappel dans l'app Rappels (faux : `set_completed` côté magasin), **alors** la tâche liée passe « terminée » au passage suivant, sans écriture en retour (anti-boucle : un second passage donne `{ envoyées: 0, reçues: 0 }`).
3. **[U]** **Quand** je change le titre, la date ou l'heure d'une tâche liée, **alors** le rappel suit ; une date retirée efface l'échéance (D4) ; **quand** je les change dans Rappels, la tâche suit (K-05 critère 10). Les notes de la tâche et ses rappels CircleTasks (N-02) ne sont jamais envoyés.
4. **[U]** **Conflit.** **Étant donné** le titre modifié des deux côtés entre deux passages, **alors** la valeur la plus récente (comparaison de la date de modification Apple et de l'horloge du champ) l'emporte et l'autre est écrite dans le journal des conflits (Y-04) avec l'espace, l'élément et le champ ; jamais de perte sans trace ; changements de **champs différents** : les deux sont gardés.
5. **[U]** **Étant donné** le réglage « Créer aussi dans Rappels » activé pour Perso avec la liste « Courses », **quand** je crée une tâche Perso, **alors** un rappel est créé dans « Courses » avec titre, date, heure et `apple_reminder_id` écrit sur la tâche (synchronisé) ; une tâche Pro ne crée rien ; réglage désactivé (défaut) : **aucun appel d'écriture** (faux espionné) ; les tâches existantes lors de l'activation ne sont pas envoyées (test).
6. **[U]** **Alors** le réglage est visible dans Réglages > Agendas > Rappels Apple, une ligne par espace avec interrupteur et liste de destination ; activer sans liste affichée dans cet espace est refusé avec la raison ; décocher la liste de destination désactive le réglage et le dit.
7. **[U]** **Étant donné** une tâche liée supprimée dans CircleTasks, **alors** la confirmation nomme Rappels, puis le rappel est supprimé au passage ; annulée dans les 5 s (T-13), rien n'est écrit ; supprimée dans Rappels, voir K-05 critère 10.
8. **[U]** **Aucun échec silencieux.** **Étant donné** un échec d'écriture (accès révoqué, rappel supprimé entre-temps, magasin indisponible), **alors** l'écriture reste due (écritures dérivées de l'état des tâches, sans file bornée ni abandon de la plus ancienne ; ADR 0008 §10.8 et §10.9 écart 3), le nombre d'écritures en attente est affiché dans l'écran Agendas et par un bandeau A-09 « {n} modification(s) n'ont pas pu être envoyées vers Rappels », réessai à chaque passage, effacé quand la file est vide ; un rappel disparu : la tâche est détachée (`external_id` effacé, `source` = `local`, ADR 0008 §10.1) avec message.
9. **[U]** **Alors** les écritures du passage utilisent les cas d'usage et les repositories seulement (aucun SQL dans la feature) ; `apple_reminder_id` écrit par une transaction (tâche + lien local).
10. **[E]** Projet `iphone` : parcours complet avec le faux (importer, terminer ici, terminer dans le faux, modifier un titre des deux côtés, créer avec réglage activé, supprimer) ; projet `pc` : le réglage de création n'est pas proposé (texte « Se règle sur l'iPhone »).
11. **[CI]** `build-ios.yml` vert ; la fixture de contrat inclut `upsert`, `set_completed`, `delete` ; capability iOS à jour (test de la liste exacte).

## Critères seulement vérifiables sur l'appareil (reportés dans `_checklist-ordre-5.md`)

- A1. Terminer une tâche liée dans CircleTasks : le rappel est terminé dans l'app Rappels (ouvrir Rappels aussitôt) ; rouvrir : redevient à faire.
- A2. Terminer dans Rappels : la tâche est terminée à l'ouverture de CircleTasks.
- A3. Modifier titre et date des deux côtés, noter le gagnant et la ligne du journal des conflits.
- A4. Réglage de création activé pour un espace : un rappel apparaît dans la bonne liste d'Apple ; synchronisation iCloud de Rappels vers un autre appareil Apple (si disponible).
- A5. Accès révoqué dans Réglages iOS pendant une modification : bandeau, file visible ; rétabli, file vidée.
