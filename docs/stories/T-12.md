# T-12 — Je duplique une tâche

Module : M1 Tâches · Ordre de construction : 1 (Socle) · Agent : **tasks-planning** · Statut : à faire

## Rappel PRD (section 4, M1)

| ID | User story | Critères d'acceptation |
| --- | --- | --- |
| T-12 | Je duplique une tâche | Copie avec titre, note, icône, espace, projet, rappels ; date proposée à choisir ; Ctrl+Maj+D sur PC, action du menu sur iPhone |

## Références visuelles

- Detail.html (iPhone) : bouton « Dupliquer » (rangée Reporter / Un jour / Dupliquer).
- PC-Aujourdhui.html : panneau détail sans bouton « Dupliquer » (raccourci seul).

## Critères testables

1. **Étant donné** une tâche sélectionnée dans une liste (PC), **quand** j'appuie sur Ctrl+Maj+D, **alors** le sélecteur de date (T-14) s'ouvre, présélectionné sur la date de la tâche d'origine (ex. original du jeu. 24 → jeu. 24 présélectionné) ; pour une tâche « Un jour », « Un jour » est présélectionné (Q8).
2. **Étant donné** la fiche détail iPhone, **quand** je touche « Dupliquer », **alors** le même sélecteur s'ouvre, avec la même présélection.
3. **Quand** je valide une date, **alors** une nouvelle tâche est créée avec : même titre, note, icône, espace, projet, heure, et une copie de chaque rappel (même avance) ; date = date choisie ; non terminée ; `carriedOver` faux.
4. **Alors** ne sont pas copiés : récurrence (la copie est « Une fois »), rattachement à l'objectif, statut terminé, ordre manuel (la copie est placée à la fin de son jour).
5. **Étant donné** le choix « Un jour » dans le sélecteur, **alors** la copie est créée sans date dans « Un jour ».
6. **Quand** je ferme le sélecteur (Échap / Fermer), **alors** rien n'est créé.
7. **Alors** un message « « <titre> » dupliquée » + « Annuler » s'affiche 5 s ; « Annuler » ou Ctrl+Z supprime la copie.
8. **Étant donné** une tâche terminée, **alors** la duplication est possible et la copie est non terminée.
9. **Alors** la fiche détail de la copie n'est pas ouverte automatiquement ; la tâche d'origine reste sélectionnée.

## Hors de cette story

- Duplication de checklist : C-04. Duplication par lot : non prévue.

## Ordre des sous-tâches

1. domain : `duplicateTask(source, date)` (champs copiés / non copiés) ; tests.
2. Repository : création tâche + rappels en transaction.
3. Cas d'usage + commande annulable `UndoKind 'duplicate'`.
4. UI : raccourci (registre `SHORTCUTS`), bouton « Dupliquer » du détail (PC et iPhone, cf. écart), message i18n.
5. Tests et e2e ; qa-test, code-reviewer, vérification product-owner.

## Écarts et points à arbitrer

- A-08 (PRD) exige un bouton « Dupliquer » dans le détail sur les deux plateformes ; PC-Aujourdhui.html ne le montre pas. Proposition : l'ajouter au panneau PC (conforme au PRD).
- Q8 : tranché (voir ci-dessous).

## Décisions d'Ali (2026-10-02)

- **Q8** : à la duplication, le sélecteur présélectionne la même date que l'original (« Un jour » si l'original est dans « Un jour ») ; l'utilisateur peut la changer avant de valider. Critères 1 et 2 ajustés.
