# S-04 — Je crée une tâche directement dans un jour

Module : M3 Semaine · Ordre de construction : 1 (Socle) · Agent : **tasks-planning** · Statut : à faire

## Rappel PRD (section 4, M3)

| ID | User story | Critères d'acceptation |
| --- | --- | --- |
| S-04 | Je crée une tâche directement dans un jour | Champ d'ajout rapide en bas de chaque jour |

## Références visuelles

- PC-Semaine.html : bouton pointillé « + Ajouter » en bas de chaque colonne.
- Semaine.html (iPhone) : bouton pointillé « + Ajouter » dessiné seulement sur le dimanche vide.

## Critères testables

1. **Étant donné** la Semaine (PC et iPhone), **alors** chaque jour, vide ou non, présente « + Ajouter » en bas de sa colonne / section.
2. **Quand** je clique « + Ajouter » du jeu. 24, **alors** il devient un champ de saisie focalisé (« Nouvelle tâche pour jeu. 24 » comme libellé accessible).
3. **Quand** je tape « Réunion d'équipe » et Entrée, **alors** la tâche est créée au jeu. 24, sans heure, dans l'espace par défaut (règle T-01 : filtre actif, Pro en « Tout »), et apparaît dans la colonne ; le champ reste ouvert et vide pour une saisie suivante.
4. **Quand** j'appuie sur Échap ou quitte le champ vide, **alors** il redevient « + Ajouter » sans rien créer ; un champ vide ou d'espaces ne crée rien.
5. **Alors** la validation du titre est celle de T-01 (trim, 1 à 200 caractères).
6. **Étant donné** un jour passé, **alors** l'ajout est possible (pas de blocage).
7. **Étant donné** l'iPhone, **alors** le clavier ne masque pas le champ (défilement automatique de la section).
8. **Alors** la création de 5 tâches réparties sur la semaine se fait sans quitter l'écran (parcours clé 3), chacune visible < 500 ms après Entrée.

## Hors de cette story

- Langage naturel dans le champ (heure) : Q-02 (ordre 3). Bouton + global (feuille complète) : T-01, avec date présélectionnée = aujourd'hui.

## Ordre des sous-tâches

1. Réutiliser le cas d'usage de création de T-01 avec date imposée.
2. UI : bouton / champ par jour (PC, iPhone), gestion du focus et du clavier iOS.
3. Tests Testing Library, e2e (parcours clé 3).
4. qa-test, code-reviewer, vérification product-owner.

## Écarts

- Semaine.html ne dessine « + Ajouter » que sur le jour vide ; le PRD l'exige « en bas de chaque jour » : le PRD prime (proposition).
