SYNCHRONISATION

Associer l'iPhone

Ce code transmet la clé de chiffrement de vos données. Il ne passe jamais par iCloud.

1Sur l'iPhone, ouvrez Réglages → Synchronisation → Associer au PC.
2Scannez ce code avec l'iPhone.
3Choisissez le même dossier iCloud Drive / CircleTasks sur l'iPhone.
Clé de secours Imprimez-la et rangez-la. Sans elle, les données iCloud seraient perdues si les deux appareils étaient réinitialisés.
En attente de l'iPhone… Code valable 5 minutes · Nouveau code
